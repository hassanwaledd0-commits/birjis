## 2. التدقيق (Audit)

| الفئة | المعرّف | المستعمل خارج الرموز (صلب) |
|---|---|---|
| ألوان | 24 متغير لون | **184** استعمال hex (112 لوناً مختلفاً) مقابل **599** استعمال `var(--…)` |
| خط | 6 درجات | **153 من 214** تصريح حجم خط خارج السلّم (26 قيمة مختلفة؛ الأكثر 13 و14 و12.5 و11) |
| حواف | 4 درجات | **66 من 109** تصريح نصف قطر خارج السلّم (12 و16 و999 للشرائح) |
| مسافات | 7 درجات | **211 من 352** تصريح مسافة خارج السلّم (22 قيمة مختلفة) |

**قراءة الأرقام:** الألوان محكومة جيداً (نسبة 3:1 لصالح الرموز، ومعظم الـhex للمجسّم/الرسم أو الأنظمة). أما الخط والمسافات والحواف فالسلّم المعرّف **لا يغطي** أغلب الاستعمال: السلالم صُمّمت بعد أن كتب الكود الأقدم قيماً مباشرة (13، 12.5، 14 …). لا يُنصح بتعميم تلقائي (سيغيّر التخطيط بكل الصفحات)؛ الصحيح تحويل تدريجي عند لمس كل مكوّن.

**المكوّنات الجديدة بهذه النسخة تستعمل الرموز:** CSS الدفتر (`#nbCss`) كله `var(--s*)` و`--fs-sm` و`--r-lg` و`--accent` و`--line`؛ الـhex الوحيدة هي ألوان الأقلام الستة (بيانات لا نمط). لوحة «المركز» (`.fhub*`، 25 قاعدة): 8 استعمالات `var(--…)` و5 hex (3 ألوان) لأنها فوق مشهد الطيران بخلفية شبه شفافة خاصة بالطيران، وحجم الخط 10.5–14.5 px.

### أولويات (مرتّبة بالأثر)
1. **سلّم الخط:** أضف `--fs-2xs 11` و`--fs-sm2 13` و`--fs-md2 14` للقيم الأكثر استعمالاً (13: 40 مرة، 14: 37، 12.5: 15) ثم حوّلها تدريجياً.
2. **الحواف:** أضف `--r-pill 999px` و`--r-md 12px` (12: 24 مرة، 999: 19، 16: 7).
3. **المسافات:** القيم الشائعة خارج السلّم: 6 (76 مرة) و10 (52) و2 (23) و5 (19) و14 (10)؛ أضف `--s-half 6px` و`--s-tight 10px` أو حوّلها لأقرب درجة بعد مراجعة بصرية.
4. **ألوان الأنظمة** ثابتة بالمجسّم والمخططات (كل منها يخدم تمييزاً وظيفياً)؛ لا تُلمس بدون فحص تباين.

## 3. مكوّن: لوحة «المركز» (Takeoff / Landing Hub)

**الوصف:** لوحة عائمة واحدة تجمع كل أدوات الإقلاع والهبوط بدل أزرار مفردة على شاشة الطيران. الملفات: `src/p8f.js` (`flyHub`, `flyHubBuild`, `ffHubPlace`)، CSS `.fhub*` بـ`src/p1s.html`. الاختبار: `tests/hub_test.py`.

| متغيّر | الاستعمال |
|---|---|
| زر الفتح `#fHubB` (`.fhubB`) | الشريط الأيسر؛ مفتاح **H**؛ `aria-expanded` و`aria-controls` |
| شرائح القلابات `#fFlapDt` | واحدة لكل وضع قلابات بالطائرة (`s.A.flaps`)؛ العدد يختلف بين الطائرات الثلاث |
| بلاطة حالة `.fhubTile` (`aria-pressed`) | العجلات، السبويلر، فرامل الوقوف، عكس الدفع |
| بلاطة ضغط مطوّل | الفرامل (`pointerdown/up`) |

| الحالة | المظهر / السلوك |
|---|---|
| مغلقة | `hidden`؛ الزر بنمط `.fb.w` |
| مفتوحة | الزر `.on` بلون التأكيد؛ تركيز يذهب لزر «+» القلابات؛ توضع بأقرب مساحة حرة (لا تغطي أزراراً) |
| بلاطة مفعّلة | `aria-pressed=true`: حد وخلفية بلون التأكيد |
| غير مسموح (أرضي فقط أو جوي فقط) | رسالة قصيرة (`flyMsg`) ولا تغيير بالحالة |
| الطيار الآلي مفتوح | اللوحتان لا تظهران معاً |

**إمكانية الوصول:** `role="group"` مسمّاة (`aria-labelledby`)؛ كل أزرارها أزرار حقيقية؛ الأهداف ≥ 36 px ارتفاعاً (≥ 30 عرضاً لشرائح 7 أوضاع)؛ Escape ونقرة خارجية يغلقان ويعيدان التركيز للزر؛ تباين النص 12:1 (التسميات) و7.2:1 (الاختصارات الصغيرة)؛ يعمل باللمس والفأرة والكيبورد (H).

| ✅ افعل | ❌ لا تفعل |
|---|---|
| أضف أداة جديدة كبلاطة داخل `.fhubT` مع `data-fa` | لا ترجع زراً مفرداً للشاشة الرئيسية |
| اترك الموضع لـ`ffHubPlace` | لا تثبّت إحداثيات |

## 4. مكوّن: الدفتر (Notebook)

**الوصف:** تبويب مستقل (`notes`، مجموعة learn) للرسم والنص والتسجيل. `src/x_notes.js`؛ الاختبار `tests/nb_test.py`.

| الجزء | ملاحظة |
|---|---|
| اللوح `.nbBoard` | 4:3 ثابت، canvas للرسم + مربعات نص حقيقية فوقه |
| الأدوات `.nbTools` | قلم / ممحاة / نص / ألوان (6) / سماكة (3) / تراجع وإعادة / صفحات / تصدير PNG؛ كلها `.btn` بارتفاع ≥ 40 px |
| التسجيل `.nbRecBar` | صوت / فيديو (حد 15 و5 دقائق)؛ بديل اختيار ملف عند منع الإذن |
| التخزين | IndexedDB `birjis-notes`؛ بدونه يعمل للجلسة مع تنبيه |
| طول الصفحة (v37) `.nbLen` | «− / الأسطر: N / ＋ أسطر»؛ الصفحة تطول تلقائياً عند الكتابة بآخرها؛ الإحداثيات بوحدة الصفحة الأساسية فلا يتحرك المحتوى |
| نوع الورق (v37) `#nbPaper` | مسطّر / مربعات / فارغ لكل صفحة (`data-paper`) |
| الصور (v37) `.nbImgs` | تحت الحبر (يُرسم فوقها)؛ من الجهاز أو من زر «للدفتر» بالعارض؛ لها `alt` وتُحذف من قائمة المرفقات |

| الحالة | السلوك |
|---|---|
| أداة مفعّلة | `aria-pressed=true`، لون التأكيد |
| تسجيل جارٍ | عدّاد زمن وزر إيقاف؛ الكاميرا/الميكروفون يُغلقان عند مغادرة التبويب |
| إذن مرفوض / مدعوم غير | رسالة مكتوبة + «اختيار ملف» |
| لا IndexedDB | يعمل للجلسة ويُعلم المستخدم |

**إمكانية الوصول:** مربعات النص `<textarea>` حقيقية بتسميات؛ الرسم بالإصبع ميزة لمسية فقط، ولا يُشترط للمحتوى (النص والتسجيل بدائل)؛ الأزرار لها `aria-label`؛ الأهداف ≥ 36 px (فحص بـ`nb_test.py`). **فجوة معروفة:** الرسم نفسه لا بديل له لقارئ الشاشة (يمكن إضافة وصف نصي لكل صفحة).

| ✅ افعل | ❌ لا تفعل |
|---|---|
| خزّن الرسم نقاطاً مطبَّعة (مستقل عن الشاشة) | لا تخزّن بكسلات |
| أغلق مجرى الجهاز عند الخروج | لا تترك الكاميرا مفتوحة بالخلفية |
